## Cómo abrir el proyecto

1. Descarga y descomprime esta carpeta.
2. Abre la carpeta `CiudadaniaDigital_Actividad2_Completo` en Visual Studio Code.
3. Abre el archivo `index.html`.
4. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server** si tienes la extensión.
5. Si no tienes Live Server, también puedes abrir `index.html` directamente desde el explorador de archivos.

## Antes de entregar

En `index.html` reemplaza:

- `[NOMBRE COMPLETO]`
- `[CÓDIGO DE ESTUDIANTE]`

por tus datos.

Después publica el sitio en una plataforma como GitHub Pages, Netlify, Canva Websites, Wix o Google Sites, según lo permitido por tu curso.

La actividad solicita que el micrositio sea público y que el enlace se incluya en el documento PDF de entrega.

## Archivos

- index.html: página principal.
- style.css: diseño y adaptación a celular.
- script.js: menú móvil y checklist interactivo.
- README.txt: instrucciones.
